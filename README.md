# JobShield – Fake Job Detection and Verification System

## About the Project
JobShield is a web-based application designed to help users identify potentially fraudulent job postings. It analyzes job information and provides a risk assessment to help users make safer job-search decisions.

## Features
- User registration and login
- Job posting analysis and risk assessment
- Machine learning-based fake job detection
- Job verification history
- Suspicious job reporting
- Admin dashboard and report management
- Password reset using OTP verification

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Machine Learning:** TF-IDF and Logistic Regression
- **Database:** MySQL
- **Libraries:** Flask-Bcrypt and other required Python packages

## Project Modules
1. User Management
2. Job Verification
3. Verification History
4. Job Reporting
5. Admin Management

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Open the project folder:
   ```bash
   cd JobShield
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Configure your database credentials and environment variables.
5. Set up the database using the project's SQL file.
6. Start the Flask application:
   ```bash
   python app.py
   ```

## Disclaimer
JobShield provides an automated risk assessment and is intended for educational purposes. Its results should not be treated as a guarantee that a job posting is genuine or fraudulent.
